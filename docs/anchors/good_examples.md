### Reference 台词 1
> "注意看至尊宝戴上金箍的那一刻，镜头给了特写但不是脸，而是他颤抖的手——周星驰在用身体语言表达'被迫成长的痛苦'，这种'手比脸诚实'的细节，比任何台词都戳人。"

**为什么好**:

**为什么好**:

## 使用指南

### 如何在 prompt 中引用
```python
# 在 narrative_ir.py 的 USER_PROMPT_TEMPLATE 中添加：
few_shot_references = load_good_examples()  # 从 good_examples.md 随机抽取 2-3 条
```

### 如何评估新案例是否合格
- ✅ 必须包含"具体观察 + 立场解读"
- ✅ 具体观察必须是可验证的事实（时间/镜头/用词/节奏）
- ✅ 立场解读必须有信息量（解释为什么/有什么效果/有什么问题）
- ❌ 禁止空洞形容词（绝了/洗脑/拉满/良心）
- ❌ 禁止纯描述句（"男主走进房间"）
