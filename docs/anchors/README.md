# Anchors — 好二创锚点案例集与反例库

> **用途**: 为 LLM 提供真人二创 UP 主的 reference 台词（供 RAG 引用）+ AI 味反例（供 stage1_floor_check.py 零容忍检测）  
> **维护者**: Future Self + 消费者角色  
> **更新频率**: 每季度新增 ≥3 条 good examples；每次发现新 AI 味模式时新增 anti examples

---

## 📌 好二创工程隔离定义（P0-5）

> **好二创 ≠ 描述句堆砌；好二创最低门槛 = 至少 1 个判断式钩子（前 5 句内）+ 段落主体的判断句占比 > 描述句占比；其余事后看反例库 + 锚点案例。**

**关键约束（工程隔离条款）**：
- ✅ **此定义只能出现在本文件**（`docs/anchors/README.md`）
- ❌ **不得进入任何 prompt 文件**（`src/autoclip/prompts/` 下禁止出现 "judgment ratio" / "判断句占比" 等字样）
- ❌ **不得进入任何 evaluator 评分公式**（防止反向蒸馏成约束规则）
- ✅ **CI 检查**：`grep -r 'judgment ratio\|判断句占比' src/autoclip/prompts/` 必须为空，否则 lint fail

**理由**：
- Future Self（C2-R4）"必须有反向定义"是维护性硬约束（6 个月后无法判断 patch 是升级成规则还是丢掉）
- Devil's Advocate（C2-R2）"任何前瞻性定义都会被工程师转化为约束"是真实历史规律（autoclip v0.5→v0.7 已发生 3 次描述→约束退化）
- Chair 决议通过"工程隔离条款"两全：定义存在但物理位置和评分体系隔离

## 📂 文件结构

```
docs/anchors/
├── README.md              # 本文件（工程隔离定义 + 人工 review checklist）
├── good_examples.md       # 好二创锚点案例集（≥3 条真人 reference 台词）
└── anti_examples.md       # AI 味反例库（U2 + U3 典型特征）
```

### good_examples.md
收录真人二创 UP 主的 reference 台词，供 LLM RAG 引用：
- 木鱼水心《大话西游》解说（情感解读类）
- 刘老师《情书》解说（文艺片解读类）
- LKs 开场公式（科技/知识区通用钩子）

每条 reference 包含：
- 具体观察（可验证的事实：时间/镜头/用词/节奏）
- 立场解读（为什么这样设计/有什么效果/有什么问题）
- 为什么好（解释符合好二创标准的原因）

### anti_examples.md
收录 autoclip 生成的失败案例，供 `stage1_floor_check.py` 零容忍检测：
- U2 反例：上帝视角 + 套话情绪 + 教学口气 + 陈述事实零钩子
- U3 反例：刚达标但仍是 AI 味（堆黑话词）

每条反例包含：
- 坏例子原文
- 问题分析（指出 AI 味的具体特征）
- 修正建议（展示什么是好的写法）

## ✅ 人工 Review Checklist

在 v0.8 阶段完成后，每批次生成的 narrative IR 需通过以下人工 review 检查：

### 1. 钩子检查（前 5 句内）
- [ ] 至少有 1 个强洞察钩子
- [ ] 钩子满足以下任一条件：
  - 揭示设计意图（"导演故意..."）
  - 指出矛盾（"画面说 A，声音说 B..."）
  - 发现细节（"注意第 X 秒的..."）
  - 吐槽/反差（"你以为...结果..."）
- [ ] 钩子是"具体观察 + 立场解读"格式

### 2. 判断句占比检查
- [ ] 段落主体的判断句占比 > 描述句占比
- [ ] 判断句定义：把句子加上"XX（UP 主名）认为"前缀仍成立
- [ ] 描述句定义：陈述事实/动作/画面（如"男主走进房间"）

### 3. 人格套用检查
- [ ] 已套用 docs/personas/ 中的某一种人格
- [ ] 人格风格一致（无混搭）
- [ ] 冒犯型人格使用时未越界（无人身攻击）

### 4. 反例库触发检查
- [ ] 未命中 anti_examples.md 中的任何反例
- [ ] 无空洞形容词（绝了/洗脑/拉满/良心/顶得住/爆棚/有福了/DNA 动了/拿捏/破防）
- [ ] 无上帝视角（"旁白欢迎小朋友""主持人介绍..."）
- [ ] 无教学口气（"今天要学...""让我们一起来..."）
- [ ] 无纯描述句零钩子

### 5. 具体观察 + 立场解读检查
- [ ] 每句话包含具体观察（时间/镜头/用词/节奏/画面细节）
- [ ] 每句话包含立场解读（为什么这样设计/有什么效果/有什么问题/你如何评价）
- [ ] 具体观察是可验证的事实（非主观臆断）
- [ ] 立场解读有信息量（非简单重复情绪）
