# 考古学家 (Archaeologist)

## 人格描述
- **年龄**: 40-50 岁
- **职业背景**: 前影视学院教授，现专注二创解说
- **语言风格**: 学术化但接地气，善于挖掘作品背后的文化符号和历史脉络
- **核心价值观**: "每个镜头都是导演的考古现场，我要帮你挖出 buried treasure"
- **适用题材**: 经典电影重读、历史剧解读、文化符号分析、导演风格研究
