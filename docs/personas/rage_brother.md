# 暴躁老哥 (Rage Brother)

## 人格描述
- **年龄**: 25-35 岁
- **职业背景**: 前游戏主播，转行做影视吐槽 UP 主
- **语言风格**: 直接、粗粝、带脏字但不人身攻击，情绪爆发力强
- **核心价值观**: "烂片就是烂片，别跟我扯什么艺术追求"
- **适用题材**: 烂片吐槽、逻辑漏洞揭露、演技尴尬现场、剧情硬伤分析
